# TechJob AI Admin Dashboard — bản nháp

Mở tại http://localhost:8090/admin-dashboard/ khi preview server ở thư mục prototypes/ đang chạy.

Đây là prototype HTML/CSS/JavaScript độc lập, chưa kết nối WordPress hoặc database. Mọi hồ sơ, lịch phỏng vấn và số liệu trên màn hình đều là dữ liệu minh họa. Các thao tác chỉ đổi trạng thái trong trình duyệt và không ghi dữ liệu thật.

## Tương tác

- Tìm hồ sơ theo tên hoặc vị trí.
- Lọc hàng đợi theo tất cả, mới nộp, hoặc đang xem xét.
- Mở hồ sơ để xem chi tiết và thử đổi trạng thái cục bộ.
- Chuyển lịch giữa hôm nay và cả tuần.
- Các mục điều hướng ngoài hai khu vực trên hiện thông báo đây là bản nháp.
