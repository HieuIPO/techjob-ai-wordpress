# Job explorer prototype override

The generated system recommends flat design, professional blue and success green. Apply these semantic colors to a working job explorer. Use a two-column result grid with a compact filter sidebar rather than the generated single-column marketing CTA pattern, because users need to scan salary, location, skill and experience together.

Use system Segoe UI/sans typography for reliable Vietnamese rendering in this offline prototype. Blue #0369A1 is structural/action color; darkened green #16703C ensures white text contrast for the search CTA. White surfaces and a restrained cool-gray board background; no shadows on cards. 4/8px spacing rhythm; 44px minimum essential interactive targets.

Scope: light-mode visual concept only; four fictional jobs; in-memory filters/saved list/detail/practice dialog, no database writes and no AI connection. This draft reuses working interaction code and primitive styles from career-board, with different composition, palette, size hierarchy and cards. No claim of complete production accessibility or dark-mode audit.
